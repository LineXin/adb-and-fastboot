# ⚡ ADB & FASTBOOT LineXin Edition

Графическая утилита на базе **PyQt5** для Windows, позволяющая управлять Android-устройствами, прошивать образы и работать с ADB / Fastboot в пару кликов без ручного ввода команд.

## ✨ Основные возможности
* **Полная автономность:** Автоматическая загрузка и распаковка актуальных Google Platform Tools при первом запуске.
* **ADB & Scrcpy:** Установка APK в один клик, подключение по Wi-Fi (Wireless ADB), трансляция экрана на ПК через Scrcpy, обход Setup Wizard, скриншоты на рабочий стол.
* **Fastboot & GSI:** Переход в режим Fastbootd, прошивка GSI-образов, отключение проверки целостности (`vbmeta`), очистка разделов.
* **Recovery & Root:** Прошивка TWRP, OrangeFox и PBRP через Bootloader или Sideload, установка Magisk Root.
* **Мониторинг устройства:** Модель, бренд, версия Android, патч безопасности, CPU, заряд АКБ и статус загрузчика в реальном времени.
* **Кастомизация:** 5 встроенных тем оформления, выбор собственного акцентного цвета (Color Picker) и смена языка (RU / EN) на лету.
